# Monitoreo transaccional — API de riesgo

Servicio en producción del Proyecto Final de Deep Learning y Sistemas Inteligentes
(UVG, 2026). Puntúa una transacción con tarjeta a partir de la historia reciente de la
tarjeta y decide **bloquear / revisar / aprobar** con un umbral de mínimo costo.

- `/` — demo para evaluar casos reales del periodo de prueba
- `/monitor` — panel de monitoreo (deriva, latencia, campeón vs. retador)
- `/docs` — documentación interactiva de la API

El código, el entrenamiento y el documento técnico están en el repositorio de GitHub
del proyecto.
